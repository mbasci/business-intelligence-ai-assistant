# GitHub Upload Instructions

## Recommended Repository Name

insightforge-ai-bi-assistant

## Upload These Files

- app.py
- requirements.txt
- README.md
- .gitignore
- LICENSE
- packages.txt
- sample_data/
- screenshots/
- notebooks/
- .streamlit/secrets.example.toml

## Do Not Upload

- .env
- .streamlit/secrets.toml
- real API keys
- private datasets
- client data
- PHI
- confidential business data

## GitHub Web Upload Steps

1. Create a new GitHub repository.
2. Name it `insightforge-ai-bi-assistant`.
3. Keep it public if you want it visible for portfolio review.
4. Upload the project files.
5. Commit the files.
6. Copy the repository URL.
7. Use that URL for Streamlit deployment.
